# 12. Reto final

Objetivo: que cada estudiante cierre con una muestra propia y un resumen que no mienta.

## Encargo

1. Elige una región real o cambia la categoría en la sección 05.
2. Ejecuta desde esa celda hasta la 12. Son dos páginas de 50 filas, no el archivo completo.
3. Valida `id_transaccion`.
4. Calcula el importe neto de **esa** muestra.
5. Deja el gráfico en `salida_clase04/reto_por_categoria.png`.

`ver_solucion("12")` recuerda el criterio. No hace falta otro archivo.

## El resumen

La última celda imprime OK o NO para:

- API accesible
- autenticación
- consulta
- paginación
- datos normalizados
- validaciones
- gráfico
- archivos

Solo marca OK lo que esa ejecución hizo contra la API. El modo respaldo deja esos puntos en NO.

## Qué preguntar al recoger

«¿Tu `total_pages` es mayor que las páginas que pediste? Entonces di que la extracción es parcial, aunque el gráfico se vea completo.»

## Si alguien no tiene Postman

El reto es de Colab. Swagger sirve para mirar una página de la región elegida. El gráfico y el CSV salen del cuaderno.
